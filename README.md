# HX Unbound

A community connecting independent projects that expand what Line 6 HX and Helix hardware can do.

**Looking for the editor?** The independent editor and NAM capture librarian has moved to [HX Unbound Editor](https://github.com/Suddl3/hx-unbound-editor). This repository is now the community hub.

Find device-specific NAM work, editors, capture tools, and the research behind them in the [project directory](PROJECTS.md).

## Find your starting point

- **NAM on your device:** start with the firmware projects for your exact hardware in the directory.
- **Editors and capture libraries:** compare the independent editor and HX Edit integration projects.
- **Contribute research or code:** follow the relevant project's own contribution process; shared questions can be discussed in the community.

Each project keeps its own maintainers, direction, repositories, and licensing. A directory listing is a reference, not a claim that its maintainers have joined or endorsed HX Unbound. Credit and contributions belong with the original projects.

Device support and testing differ by project and revision. Follow each project's current documentation; a working result on one HX device does not establish compatibility with another.

## Community

[Join HX Unbound on Discord](https://discord.gg/cMpWeu3MgK) to meet other builders, share findings, and get involved. The invite opens in **start-here**.

The channels are **start-here**, **projects**, **development**, **testing-and-help**, **general**, and **repo-updates**. The project directory is maintained here; Discord hosts introductions, discussions, and collaboration.

**Repository updates:** [#repo-updates](https://discord.com/channels/1569415462666899638/1569845602626441246) receives new releases, newly opened pull requests, and merged pull requests, checked hourly by GitHub Actions. The [project directory](PROJECTS.md) is also the monitoring list: adding a repo to its main project tables automatically includes it on the next check. Foundational references are excluded. Each new project starts with a quiet baseline; historical updates are not reposted. See the [monitor documentation](monitor/README.md).

## Add or correct a project

Suggest a change with the repository URL, project name, repository owner or maintainer, purpose, supported hardware, current limitations, and an official source for those details. Maintainers are welcome to correct their descriptions and indicate whether they want to participate in the community.

HX Unbound is independent of Line 6 and Yamaha Guitar Group.

## Existing editor checkouts

If you cloned this address when it contained the editor, update that checkout's remote before fetching or pushing:

```sh
git remote set-url origin https://github.com/Suddl3/hx-unbound-editor.git
git remote -v
```

The editor's history remains in the renamed repository. This hub has its own history; do not pull it into an existing editor checkout.
